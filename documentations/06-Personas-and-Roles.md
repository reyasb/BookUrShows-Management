# Personas and Responsibilities

## Customer

The Customer can:

- Submit movie ticket requests.
- Enter booking information.
- Review booking details.
- Confirm a booking.
- Cancel a booking.
- Receive booking confirmation.

## Booking Agent

The Booking Agent can:

- Check show availability.
- Verify available seats.
- Process ticket bookings.
- Allocate seats.
- Maintain booking information.

## System

The System performs:

- Data validation
- Cost calculation
- Capacity validation
- Queue routing
- SLA processing
- Ticket ID generation
- Booking confirmation correspondence
